# Kustomize Lab

A practical learning project for Kubernetes Kustomize.

## Learning objectives

- Understand Kustomize fundamentals
- Learn bases and overlays
- Work with patches and transformers
- Generate ConfigMaps and Secrets
- Integrate Kustomize with Helm
- Integrate Kustomize with Argo CD
- Build a GitOps workflow

## Environment

- Ubuntu
- RKE2
- Kubernetes
- kubectl
- Kustomize
- Git
- Argo CD

## Labs

| Directory | Topic |
|---|---|
| 01-fundamentals | Basic Kustomize concepts |
| 02-base-and-overlays | Base and overlays |

| 04-transformers | Transformers |
| 05-configmap-and-secret | Configuration generation |

| 07-helm-integration | Helm integration |
| 08-argocd-integration | Argo CD integration |
